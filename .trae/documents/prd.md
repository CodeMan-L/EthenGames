## 1. 产品概述

短剧在线观看平台，提供海量短剧内容的分类浏览、搜索、详情查看和在线播放功能。目标用户为喜爱短剧内容的观众，主打竖屏短剧、微短剧等新兴视频内容形式。
- 解决短剧内容分散、查找不便的问题，提供一站式短剧观看体验
- 面向移动端和桌面端用户，以沉浸式视觉设计吸引年轻用户群体

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 浏览、搜索、观看短剧 |
| 注册用户 | 手机号/邮箱注册 | 收藏、历史记录、个人中心 |

### 2.2 功能模块
1. **首页**: 轮播推荐、分类导航、热门短剧、最新上线、排行榜
2. **分类页**: 按类型/地区/年份筛选短剧列表
3. **搜索页**: 关键词搜索、搜索历史、热门搜索
4. **详情页**: 短剧信息、剧集列表、相关推荐
5. **播放页**: 视频播放器、选集、弹幕互动

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

| 首页 | 热门短剧 | 瀑布流展示热门短剧封面、标题、更新状态 |

## 3. 核心流程

用户打开网站 → 浏览首页推荐/分类 → 点击短剧进入详情页 → 选择集数进入播放页 → 观看视频 → 切换集数或返回浏览

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深黑 (#0a0a0f) + 玫红渐变 (#e8364e → #ff6b81) 作为强调色
- 辅助色：金色 (#f0c040) 用于评分/排行高亮
- 按钮风格：圆角胶囊按钮，渐变背景，悬停发光效果
- 字体：标题使用粗体无衬线字体，正文使用轻量无衬线字体
- 布局风格：暗色主题，卡片式布局，竖版封面为主（3:4比例）
- 图标风格：线性图标，2px描边，与暗色主题协调
- 整体氛围：影院级暗色沉浸感，霓虹渐变点缀，类似流媒体平台的高级感

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 首页 | 轮播推荐区 | 全宽渐变背景，大图+标题叠加，左右切换箭头，底部指示器 |
| 首页 | 分类导航 | 横向滚动标签栏，选中态渐变背景，胶囊形状 |
| 首页 | 热门短剧 | 竖版封面网格(3:4)，悬停放大+信息浮层，更新角标 |
| 首页 | 排行榜 | 左侧排名数字高亮，金银铜配色，右侧短剧信息 |
| 分类页 | 筛选栏 | 标签式筛选，选中态渐变，可展开更多 |
| 分类页 | 短剧列表 | 4列网格，封面+标题+标签+评分，无限滚动 |
| 搜索页 | 搜索框 | 居中大搜索框，聚焦时发光边框，搜索图标 |
| 搜索页 | 热门搜索 | 标签云布局，渐变背景标签 |
| 详情页 | 短剧信息 | 大封面+渐变遮罩+信息叠加，评分徽章 |
| 详情页 | 剧集列表 | 横向滚动方格，当前集高亮，已看集标记 |
| 播放页 | 播放器 | 全宽播放器，底部控制栏，竖屏适配 |
| 播放页 | 选集面板 | 底部抽屉式选集，网格布局 |

### 4.3 响应式设计
- 桌面优先设计，移动端自适应
- 桌面端：4列网格布局，侧边栏筛选
- 平板端：3列网格布局，顶部筛选
- 移动端：2列网格布局，底部导航，触控优化
